# Makdesi And Associates Lawyers — Homepage

Astro rebuild of the firm homepage, structured from the Advorus template mapping in `PRD.md`.

## Develop

```bash
npm run dev
```

Open [http://localhost:4321](http://localhost:4321).

Background mode (Cursor agents):

```bash
npx astro dev --background
npx astro dev status
npx astro dev stop
```

## Build

```bash
npm run build
npm run preview
```

## Content

Editable copy, practice areas, team, and reviews live in `src/data/site.ts`.
